# ClickUp card submission totals

- Problem: a new card displays the selected default ClickUp team as a string, but Save previously read only an option's `value`. The submit filter then excluded the card despite its selected task.
- Choice: persist the displayed team when saving (option value, then string, then stored team). For cards already in memory or imported, use the selected default team during filtering, without mutating the source cards. A stored team always wins; no task or no available team still excludes a card.
- Change: the ClickUp confirmation total and submit handler share one filtered dataset. The dialog counts cards without tasks separately from cards with tasks but no available team. Confirm is disabled when eligible hours are zero. The exact message `No cards have a ClickUp task yet.` is used when no cards have tasks; other zero-hour cases say `No hours are available to submit to ClickUp.` to avoid a false claim. Jira/Redmine retain the default enabled Confirm behavior. No native dialogs or controls were added, and `createClickUpTimeEntries` was not changed.
